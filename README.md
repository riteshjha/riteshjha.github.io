# Ritesh Kumar Jha — Personal Bio Site

Personal portfolio and bio site built with pure HTML & CSS, hosted on GitHub Pages.

## Live Site

[https://riteshjha.github.io](https://riteshjha.github.io)

## Structure

```
bio/
├── index.html        # Main page
├── style.css         # Styles
├── README.md
└── docs/
    ├── ritesh_pp.JPG                    # Profile photo
    └── Ritesh Kumar Jha - Improved CV.pdf  # Resume (not publicly downloadable)
```

## Sections

- Hero — name, title, contact links, stats
- About — summary, strengths, languages, domains
- Skills — frontend, backend, databases, tools
- Experience — full work history timeline
- Education — academic background
- Achievements — key career highlights
- Contact — email, LinkedIn, Stack Overflow

## Deployment

This site is deployed via **GitHub Pages** as a user site.

To go live at `https://riteshkjha.github.io`:

1. Create a GitHub repo named exactly **`riteshjha.github.io`**
2. Push this code to the `main` branch
3. Go to **Settings → Pages** → set source to `main` branch, `/ (root)` folder
4. Site will be live at `https://riteshkjha.github.io` within a minute
